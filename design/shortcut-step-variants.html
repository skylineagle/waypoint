Step 4 · auto-detect the shortcut

After Add TREK Shortcut, the app detects the shortcut when you come back: it asks Shortcuts to run Add to TREK in check-only mode, which adds nothing, and reads the result. The first check also triggers Shortcuts' one-time "Allow Add to TREK to run actions…" prompt, so real payments never hit it. The Wallet automation itself can't be detected (iOS gives no signal until the first payment), so the last button is a proper Done/Finish.
