# Waypoint

Waypoint is a free, open-source iPhone companion for a [TREK server](https://github.com/liketrek/TREK) you host or have access to. It uses the TREK API for trips, itineraries, expenses, to-dos, and Journey photo sharing.

Waypoint is an independent project by Ofek Nesher. It is not an official TREK app and is not endorsed by the TREK project.
